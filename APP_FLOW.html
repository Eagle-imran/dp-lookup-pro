Traps worth knowing before you change anything

Each of these has already cost a debugging cycle.

Layers 193/194 reject spatial queries. Any /query carrying a geometry — polygon, envelope or point, with or without distance — returns HTTP 200 wrapping {"error":{"code":400}}. Only attribute queries succeed. Road data must come from /identify.
CRZ line layers can never match. IDs 31, 1118, 2212–2214 and 2240–2243 are all boundary lines (High Tide Line, Hazard Line…). A point-identify cannot intersect a line, so using them for CRZ returns NO for every plot. Use the zone polygons.
Village names are exact and cadastral. 128 valid values, not modern locality names. BANDRA is invalid — it's BANDRA-A…BANDRA-I and BANDRA-EAST. Likewise KURLA - 1…KURLA - 4 and BHANDUP-E/-W. Full list in START-HERE.md.
LAST_EDITED_DATE cannot revalidate the cache. It reads 2019-01-23 on every parcel — it is the bulk load date, not a per-parcel edit stamp. DP modifications don't appear on the parcel record either (APPROVAL_NO is null even for plots that have one, such as Byculla 1605 with its 2024 order); they live in layer 192.
AREA_APP_SQ_MTRS is null on some plots. Malabar Hill 518 and Tardeo 264 have no approved area on MCGM record. SHAPE.AREA is populated and already in true ground square metres, so it is used as a fallback — but it is the digitised area, not the approved one, and the two differ by up to 7% where both exist. Always read plot_identity.area_source before quoting a figure.
Clear the cache before any retest. A stale entry silently replays old behaviour and will make a correct fix look like it failed.

Issue register

Every defect previously listed here was fixed on 2026-07-28 and is recorded below. Full detail, root causes and validation evidence in APP_FLOW.json.

Register clear

No open defects

All 13 tracked issues are closed. 41 offline tests now guard the logic that had no coverage before — run uv run pytest -q before and after any change.

Fixed on 2026-07-28

Validated in both directions — a coastal plot that must read YES and an inland plot that must read NO.

Fixed

CRZ false negative on every plot

The layer list held only boundary lines, so CRZ could only ever return NO. Replaced with zone polygons [14, 1264, 1548], and the sub-tier now reports as YES (CRZ II). Worli 886/947 and Bandra-A 409 flipped to YES; Byculla 1605 and Tardeo 264 correctly stayed NO.

Fixed

Cache policy matched to real data velocity

TTL raised 24 h → 30 days, reasoned from the data rather than guessed: layer 13 has been frozen since 2019-01-23 and zoning changes only by gazetted order. A hit now verifies every promised file still exists — previously a deleted bundle produced a confident success pointing at seven missing files. Age is reported on every hit via cached_at, cache_age_days and cache_expires_in_days, so staleness is never silent. --no-cache forces a fresh check.

Fixed

Blank plot areas now fall back to geometry

Where MCGM has no approved area, the digitised SHAPE.AREA is used and clearly labelled — Malabar Hill 518 went from blank to 2,450.16 m², Tardeo 264 to 2,539.25 m². Plots that already had an approved area are byte-identical. The PDF states “DERIVED from plot boundary” so a derived figure is never mistaken for an official one.

Fixed

Silent failures no longer become authoritative reports

A failed identify call now aborts the run with a clear error instead of emitting zone='Unknown', CRZ='NO' and a full PDF. Non-fatal failures surface in metadata.warnings with a metadata.complete flag, and a run carrying warnings is never cached. Every response is parsed through usable_json(), which rejects HTTP 200 bodies carrying an ArcGIS error key. Request timeout raised 10 s → 20 s.

Fixed

Cache expiry, bypass, and correct location

Entries are timestamped and expire after 24 h; --no-cache forces a fresh fetch. The store now lives at <output_dir>/.cache_store.json instead of a CWD-relative path. Legacy untimestamped entries — which hold pre-fix CRZ answers — are treated as expired.

Fixed

Input validation, escaping, and packaging

Village and CTS values pass a character whitelist before reaching the WHERE clause. KML and ReportLab data values are XML-escaped. pyproject.toml gained hatchling packaging and a dp-lookup-pro console script, the shebang is portable, and the Pillow floor is >=10.1.0 to match the font_size= requirement.

Fixed

Road detection missing abutting roads

Two dead /query calls removed and boundary-edge probes added alongside the original centroid and corner probes. Mohili 732 went from None to 21.35 m. The probes are additive on purpose — an earlier attempt that replaced the corner probes regressed Worli 947.
